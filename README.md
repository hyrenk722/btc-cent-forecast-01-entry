Forecasts Bitcoin's price 4 hours ahead from the last 72 hours of 1-minute closes: the last price plus a half-shrunk 12-hour trend extrapolation. Practice score 44,314 cents mean absolute error on the 5 locally verifiable practice cases, vs 47,055 for the last-price baseline.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
